# Stadium Crisis Simulator

## Product

Stadium Crisis Simulator is an AI-powered decision-support system for
stadium organizers. It analyzes stadium crowd and operational data,
predicts developing bottlenecks, evaluates possible interventions,
and recommends a safe and feasible action before the situation
becomes critical.

## Persona

Organizer

## Verticals

1. Crowd Management
2. Real-Time Decisions

## Core Problem

During a major stadium event, large crowds can suddenly create
dangerous bottlenecks at gates, exits, or transportation points.
An organizer needs to know not only what is happening now, but
what is likely to happen next and which intervention would best
reduce the risk.

## Core Question

"What should the organizer do BEFORE the bottleneck happens?"

## Main Differentiator

Instead of only detecting or predicting a crowd problem, the system
allows the organizer to simulate different interventions and compare
their predicted outcomes before deciding what action to take.

## Core Workflow

Operational Data
→ Data Validation
→ Risk Calculation
→ Bottleneck Prediction
→ GenAI Reasoning
→ Recommended Action
→ What-if Simulation
→ Scenario Comparison
→ Organizer Decision

## AI Responsibilities

- Understand the operational context
- Identify the most urgent risk
- Evaluate possible interventions
- Compare intervention outcomes
- Recommend one feasible action
- Explain the recommendation in plain English

## Non-AI Responsibilities

- Validate uploaded data
- Perform numerical calculations
- Calculate crowd occupancy
- Calculate net crowd flow
- Estimate time to capacity
- Enforce resource constraints
- Handle file uploads safely
- Store and transmit data
- Display results

## Main Screens

1. Operations Dashboard
2. AI Recommendation
3. What-if Crisis Simulator
4. Data Upload

## Input

Synthetic or uploaded stadium operational data.

## Output

- Risk level
- Estimated time to critical condition
- Recommended intervention
- Explanation
- Alternative scenarios
- Predicted scenario outcomes
